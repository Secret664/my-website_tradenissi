大衆心理と相場の本質

相場の正体 — 最上位定義
相場は注文のぶつかり合いではなく、損切りの連鎖で動く
上昇　＝　売りの損切り（強制買い）＋ 新規買いの流入
下落　＝　買いの損切り（強制売り）＋ 新規売りの流入
相場を動かすエネルギーの正体は「間違えた人の後始末」である。
市場参加者 — 3種類と役割
逆張り勢
トレンドに逆らって売りで入る。高値付近で売りを積み上げる。損切りラインを高値の上に置いている。
→ 3波の「燃料タンク」
順張り勢
トレンド方向に入っている。「まだ伸びる」と判断して保有継続。売り圧力を消す存在。
→ 売り圧力を消す存在
新規参入勢
ブレイクを確認してから順張りで参入。遅乗りだがさらに価格を押し上げる。5波では主役。
→ 3波後半・5波の主動力
3波が爆発する瞬間の構造
逆張り勢の損切り（強制買い）＋ 順張り勢の保有継続（売り圧力ゼロ）＋ 新規勢の追随買い
→ 三者が同時に「買い方向」に動く → 売り注文が消滅 → 一方向に加速
大衆心理 — 6段階サイクル
1
相場が上昇し始める — 1波
「まだ戻す」「行きすぎ」と逆張り勢が売りを積み始める。売りポジションが蓄積される。
2
一度押す — 2波
逆張り勢が「やっぱり下落だ」と確信を深め、さらに売りを追加。売りポジションが最大化される。
3
1波の高値を超えるブレイク — 3波の起点
逆張り勢の損切りライン（高値）を突破。損切りが一斉発動 = 強制的な買い注文が殺到。これが3波爆発の正体。
4
連鎖的に損切りが広がる — 3波の継続
1回目の損切りが次の損切りラインを突破 → さらに損切り発動。これが繰り返される。「止まる理由が存在しない状態」。
5
損切りが枯れる — 4波
逆張り勢の損切りが完了。エネルギーが一時的に減少。調整（押し目）が入る。この深さは不確定。
6
新規勢が押し目と判断して参入 — 5波
「安くなった」と押し目買い勢が流入。トレンド方向が確定したと確信した新規勢も追随。勝率が高い理由はここ。
1波の長さ — 全エネルギーを決める理由
1波が短い ◎
燃料が満タンの状態
1波の上昇中に逆張り勢は損切りしていない。「含み益があるから利確しない」。売りポジションが大量に残存。

3波のブレイク時に一気に全員の損切りが連鎖 → 爆発的な上昇
1波が長い ✕
燃料切れの状態
1波が長い = すでに損切りが大量発生済み。逆張り勢は「やられる前に逃げた」状態。

3波到達時には売りポジションがほぼ残っていない → エネルギー不足・伸びない
共通認識 — 価格を動かすメカニズム
なぜ前日高値・直近高値で損切りが集中するのか
前日高値
全市場参加者が共通して認識できるライン。「昨日のピークを超えたら本物の上昇」という大衆判断が一致 → 同タイミングで損切り・新規参入が集中 → 価格が反応する。
直近高値
短期の下落トレンド中に形成されたライン。15分足の売り勢が「ここを超えたら負け」と意識する損切りポイント。波形を読めないと特定できない。
本質：「多くの人が同じ場所を見る」という集合心理が、そのラインを「意味のある価格」に変える。
ダマシの正体 — 「損切りが発生しないブレイク」
ダマシの発生条件
抜けたのに伸びない
→ヒゲだけブレイク（実体が伴わない）
→利確が出ている（買い勢が逃げている）
→逆張り勢が参入している（ダイバージェンス）
→損切りポジションが少ない（誰も困っていない）
本物のブレイクの条件
損切りが発生する構造がある
→実体で明確に抜ける
→利確が出ない（順張り勢が保有継続）
→逆張りが入らない（ストキャス切り上げ）
→初動段階（MACD 0付近）
3波と5波 — 大衆心理の質的違い
3波の大衆心理
混乱・恐怖・強制
逆張り勢が「やばい、逃げなければ」と恐怖で損切りする。感情的な強制決済。合理的判断ではなく痛みからの逃走。だから一気に動く。
VS
5波の大衆心理
安心・確信・合理
押し目を見て「安く買えるチャンス」と合理的に判断して参入。確信を持った計画的な買い。だから再現性が高くテクニカルが効く。
このロジックの本質（プロ視点）
「強いから入る」ではなく「邪魔がいないから入る」（3波）。「安いから入る」でもなく「最安値付近であることが確認できたから入る」（5波）。どちらも相場を"感じる"のではなく"参加者の行動を読む"。
N字と時間 — ローソク本数が示す心理状態
5〜8本（短いN字）
売り方がまだ生きている
急速な押しで逆張り勢が逃げる前にブレイクが来る。損切りが大量に残存 → 3波の爆発力が最大。「恐怖が蓄積されたまま爆発する」。
8本超〜（長いN字）
売り方がじわじわ撤退済み
時間をかけて損切りが消化される。ブレイク時には残存ポジションが少ない → 5波的な「新規参入が主役」の動きになる。
インジケーター — 本当の役割
MACD
初動検知装置。「これから資金が流入する」タイミングを捉える。0付近 = まだ誰も乗っていない初期段階。
ストキャス
「売りポジションが今もいるか」の検出器。切り上げ = 売る理由がない状態。ダイバージェンス = 売りが待機中。
ブレイク
損切りトリガー。高値更新 = 売りの損切りが確定的に発動する物理的なイベント。
正しい順序
インジは「参加者の行動状態」を数値化したもの。波動と水平線で「どこで誰が損切りするか」を先に特定し、インジはその最終確認に使う。逆順は論外。
究極の一文 — すべてを貫く本質
負ける人の行動を利用するアルゴリズム

焼く（3波）

遅乗り勢
